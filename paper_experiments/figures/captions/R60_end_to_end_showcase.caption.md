**R60: end-to-end showcase.** (A) Target two-mode Gaussian circuit R(0.4) on mode 0,
S(0.3) on mode 1, CZ(0.8), R(-0.6) on mode 1 (hbar = 2, interleaved quadratures). (B) The
complete weighted cluster graph produced by `Circuit.compile(squeezing=1.5)`
before any flow analysis: 23 modes, 22 CZ edges
(inputs blue squares, outputs green diamonds, thick outlines = homodyne-measured). (C) The
certified CV flow found by `flows.analyze` (Booth-Markham real-linear condition), drawn in
its 13 measurement layers (each node labelled with its layer Lk), with all
45 classical dependencies of its correction map (the compiled
pattern uses its own causal schedule, which orders 2 of
these pairs differently). (D) The 21
outcome-dependent displacements the compiled pattern executes (coefficients of raw homodyne
records); the flow's standard-form map has 45 entries and a pattern
executing exactly that map gives the same channel to 1.2e-12.
(E) Conditional output means of 4000 `native-gaussian` trajectories
(seeds 60-4059, coherent inputs alpha = 0.6+0.2i, -0.3+0.5i):
they scatter around S mu (+) because finite squeezing leaves an outcome-dependent shift; the
dashed ellipses are the predicted 2-sigma spread (S V S^T + N minus the conditional
covariance); largest z-scores 1.43 (mean) and 1.87
(covariance), criterion <= 5.0. (F) The intended map S is independent of r
(max |S(r) - S_analytic| <= 5.6e-16); the added
noise N(r) is exactly e^(-2r) N(0) (fitted log-slope -2.0000), Tr N
= 1.2252 at r = 1.5 (13.0 dB), where
the ensemble output has fidelity 0.7393 with the ideal
output. The finite-squeezing map is a noisy channel, not the ideal unitary. Validation:
13/13 checks pass, including the analytic symplectic product (NumPy, written
independently) and identical trajectories on the NumPy `gaussian` backend (max difference
1.8e-15). Provisional timings
(shared machine): one native-gaussian run 4.6 ms,
NumPy gaussian 15.7 ms, flow analysis
0.67 s. Every panel is regenerated by
`paper_experiments/21_showcase/60_end_to_end_showcase.py`; the interactive page with all four
stages is `results/raw/R60_end_to_end_showcase.interactive.html`. Limitations: ideal homodyne detection, no loss;
the flow certificate is an infinite-squeezing statement.

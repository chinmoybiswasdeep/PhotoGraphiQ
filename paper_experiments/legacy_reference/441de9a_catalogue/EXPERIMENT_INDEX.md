# Experiment index

`../src/photographiq`) and executed at least once on this checkout; see
`STATUS.md` for the latest per-experiment run outcome, runtime and output
paths. "Independent?" marks whether the reference/oracle is computed by code
that does not call the PhotoGraphiQ function under test (a fresh NumPy/SciPy
formula, a raw Piquasso program, or Graphix). Costs are local observations
on the machine this suite was built on, not comparative performance claims.

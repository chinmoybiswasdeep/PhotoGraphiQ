# PhotoGraphiQ manuscript experiments (R1-R60)

A reproducible experiment suite behind the manuscript "PhotoGraphiQ: A photonic continuous
variable software platform to perform measurement-based quantum computing". It runs against the
package as installed from this repository (version 0.3.1, branch `upgraded`).

- **R1-R42** were written in 2026-09 on the former `manuscript-experiments` branch and migrated
  on 2026-11-13 to the upgraded engines (native C++ Gaussian, Fock and mixed-Fock; the
  `photographiq.flows` analysis). Their historical outputs are preserved unchanged in
  `legacy_reference/441de9a/`; what changed per experiment is in `UPGRADE_MIGRATION_MATRIX.md`.
- **R43-R60** (added 2026-11-13) validate the upgraded architecture: native engines, the
  sampling layer, flows and calculus, interactive visualization, GPU kernels, PhotoGraphiQML
  physical execution and an end-to-end showcase. Write-ups: `NEW_EXPERIMENTS_R43_R50.md`,
  `NEW_EXPERIMENTS_R51_R58.md`, `NEW_EXPERIMENTS_R57_R60.md`, `NEW_EXPERIMENTS_R59.md`.

| File | Purpose |
|---|---|
| `EXPERIMENT_INDEX.md` | One row per experiment: question, functionality, reference, metric, cost |
| `STATUS.md` | Latest run of every experiment: pass/fail, runtime, configuration |
| `MANUSCRIPT_MAP.md` | Suggested figures, tables and appendices, and what not to claim |
| `ISSUES_FOUND.md` | Defects and limits found while building and migrating the suite |
| `UPGRADE_MIGRATION_MATRIX.md` | R1-R42 before and after the upgrade |
| `PhotoGraphiQ_Manuscript_Experiments.ipynb` | Generated by `build_notebook.py`; runs the scripts |

## Setup

```bash
python -m pip install -e ".[dev,autodiff]"   # from the repository root; builds the native engines
```

The `dev` extra installs Piquasso, Graphix and mpmath (references used by many experiments);
`autodiff` installs JAX (R41, R42). Optional: CuPy for R58 (`gpu-cuda12` or `gpu-cuda13`),
Playwright for the browser checks of R57.

## Running

```bash
cd paper_experiments
python run_all_safe.py            # smoke + safe tiers (light experiments)
python run_all_safe.py --smoke    # quick subset (pull-request CI)
python run_all_safe.py --all      # every experiment, publication configuration (hours)
python run_all_safe.py --only R43 R60
python 17_flow_calculus/51_cv_flow_finding.py --full   # one experiment directly
python generate_tables.py         # aggregate tables/ from results/json
python build_notebook.py          # regenerate the notebook
```

From the repository root, `python scripts/reproduce_manuscript.py --mode smoke|scientific|full`
runs these suites from a copy (recorded results stay untouched) together with the tests,
benchmarks and the consistency audit (`scripts/audit_manuscript_consistency.py`).

Tiers (`run_all_safe.SCRIPTS`): **smoke** runs in seconds; **safe** is light enough for the
default run; **heavy** covers large Fock cutoffs, long benchmarks and timing studies. An
experiment whose optional dependency is missing is recorded as skipped with the reason, never as
passed. Every script exits non-zero when an acceptance criterion fails and then also writes an
`R<id>_..._FAILURES.csv` for diagnosis.

## Outputs

```
results/csv/       one CSV per experiment (machine-readable rows)
results/json/      JSON mirror with parameters and acceptance constants, plus *.metadata.json
results/raw/       serialized patterns, exports, browser and notebook evidence
figures/pdf|svg/   vector figures (manuscript formats)
figures/png/       300 dpi raster figures
figures/captions/  <figure>.caption.md, numbers formatted from the results
tables/            aggregated tables (generate_tables.py), csv + md
legacy_reference/  historical outputs, byte copies + SHA-256 manifests
```

## Provenance and reproducibility

- `metadata.py` records, for every result: timestamp, git commit and branch, whether the
  working tree was dirty, a SHA-256 over `src/`, `cpp/` and the experiment scripts (so results
  from uncommitted code remain traceable), Python and package versions, CPU, GPU, OpenMP
  threads and the native components. `tables/experiment_provenance.csv` lists it per experiment.
- Every stochastic experiment fixes its seeds; postselected Fock branches use explicit
  `measurement_outcomes` and are reported as postselected, not deterministic.
- Acceptance criteria are named constants declared before evaluation and stored in the JSON.
- Fock experiments report cutoff, retained norm and boundary population; truncation is never
  normalised away silently.
- Timing experiments use warm-up runs and repeated `perf_counter` measurements (median and
  spread). Timings are machine-specific; only the idle-machine run recorded in `STATUS.md` is
  suitable for the manuscript.

## Result categories

- **Exact within rounding** against an independent reference: R1-R7, R11-R16, R19, R21,
  R22, R24, R29-R31, R39, R40, R43, R45, R47-R49, R51-R57, R60.
- **Finite-resource approximations** (physical finite-squeezing noise, reported separately):
  R2-R10, R23, R25, R29, R34, R52, R60.
- **Fock truncation** (retained norm reported): R18-R28, R32-R35, R45-R47, R59.
- **Experimental features**: GKP (R26-R28, R59), cubic injection and Kerr synthesis (R23, R25),
  JAX estimators (R41, R42).
- **Precision-limited**: R50 (double-precision threshold probabilities fail in the many-click,
  low-squeezing regime; the error bound and the multiprecision path are the result).
- **Not supported, so not claimed**: CUDA-Q execution, general CV-ZX or CV measurement calculus,
  GPU sampling kernels.

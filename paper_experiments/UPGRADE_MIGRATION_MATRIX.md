# Upgrade migration matrix, R1-R42

Migration of the core manuscript experiments to the upgraded software (native C++ engines
`native-gaussian`, `native-fock`, `native-mixed-fock`; `photographiq.flows`; typed IR `OpenGraph`;
planner `select_backend`), done on 2026-11-13 in the working tree of branch `upgraded`
(HEAD `441de9a` + unstaged changes). Historical outputs: `legacy_reference/441de9a/` (byte copies of
`results/` and `tables/`, figure manifest with SHA-256; produced by the historical suite on branch
`manuscript-experiments`, commit 9304081 + local changes, numpy 2.5.3, piquasso 8.0.1, using only the
`gaussian`, `piquasso`, `piquasso-fock` and `piquasso-mixed-fock` engines).

Rules applied to every script: original checks and tolerances kept unchanged; new comparisons added as
extra columns/rows/panels with acceptance constants declared before evaluation; failures written to
`<ID>_FAILURES` files and raised; finite-squeezing noise reported separately from compilation (map)
error; Fock truncation reported through retained norms (never hidden by renormalisation); postselected
results labelled as conditional; timings labelled provisional (shared machine) unless
`PGQ_IDLE_MACHINE=1` is set. All numbers below are from the runs of 2026-11-13 on this machine
(Python 3.12.14 in `.venv`, native components gaussian/fock/sampling, MSVC 19.50, OpenMP on). Runtimes
are wall-clock on a machine shared with other agents.

Columns: ID / file; original question; original backend(s); updated backend(s); upgraded APIs used;
independent reference; main observables; numerical acceptance; execution result (measured); updated
figures; updated tables (results files); status; remaining limitations.

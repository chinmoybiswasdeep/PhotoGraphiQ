# Citing PhotoGraphiQ

Cite the software version and commit used in your experiment. Collective authorship
is retained until maintainers supply an authoritative author list. No DOI or
journal acceptance is claimed.

```bibtex
@software{photographiq,
  author = {{PhotoGraphiQ contributors}},
  title = {PhotoGraphiQ},
  version = {0.3.0},
  url = {https://github.com/chinmoybiswasdeep/PhotoGraphiQ}
}
```

Also cite the upstream Piquasso work, Graphix when used for structural validation,
and the scientific protocols used in your experiment. See [references](references.md).
The repository CITATION.cff supplies machine-readable software citation metadata.

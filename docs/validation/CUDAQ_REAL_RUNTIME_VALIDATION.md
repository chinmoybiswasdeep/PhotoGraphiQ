## Procedure on a supported machine

1. Use Linux (or WSL2 with an NVIDIA driver that supports CUDA in WSL) with Python ≥ 3.11.
2. Install the package and CUDA-Q: `pip install -e . "cudaq>=0.16"`.
3. Probe the install: `python -c "import photographiq.cudaq_dynamics as cq; print(cq.cudaq_probe())"`.
4. Run the tests: `python -m pytest tests/cudaq_adapter tests/hybrid -v`. The two tests above must run, not skip.
5. Run `python paper_experiments/23_hybrid_cudaq/hyb01_11_cudaq_status.py`. It then records `pending-real-run` and points to the tests.
6. Only after step 4 passes:
   - read the `target` and `simulator` that `cudaq.get_target()` reports, which are stored in every `EvolutionResult.record`;
   - confirm that the target is a GPU simulator;
   - only then measure performance (HYB-11).

Until this procedure has been carried out, no statement in this repository claims real
CUDA-Q execution, GPU execution or GPU acceleration of the hybrid executor.

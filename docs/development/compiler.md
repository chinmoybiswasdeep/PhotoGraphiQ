# Compiler development

Keep Gaussian lowering behavior stable. New source gates need direct execution references, a resource lowering rule, correction semantics and a trace entry linking generated commands. Test traced/untraced equality. Nonlinear synthesis must report its approximation method and refinement controls. Finite-energy injection is a conditional filter; do not label its output an exact unitary. New gates also need circuit glyphs, documentation and a supported-feature entry.

See [numerical policy](../validation/numerical-policy.md), [API](../api/index.md) and the [feature matrix](../validation/feature-matrix.md).

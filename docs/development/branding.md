# Branding

Use the PhotoGraphiQ wordmark with teal input nodes, amber output nodes and blue resource nodes. Non-Gaussian measurements use orange triangles. Shapes carry meaning independently of color. The logo and diagrams are original SVG assets generated in this repository; no third-party logo is embedded. Prefer SVG for documentation and PDF for publication figures. Avoid visual effects that obscure labels or imply unvalidated hardware layouts.

See [numerical policy](../validation/numerical-policy.md), [API](../api/index.md) and the [feature matrix](../validation/feature-matrix.md).

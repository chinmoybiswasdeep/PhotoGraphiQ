# PhotoGraphiQ v0.3 release report

PhotoGraphiQ **0.3.0** is implemented on `feature/v0.3`. This is an experimental
scientific software release candidate, with a documentation and usability overhaul
and four new research capabilities. No release tag, package publication, remote CI
run or Pages deployment was performed in this local implementation session.

## Delivered functionality

- Gaussian-plus-cubic compilation target, finite cubic-resource injection, and
  approximate quadrature-polynomial synthesis through degree four, including Kerr.
  Compilation traces map source gates to graph resources, measurements and corrections.
- Separate mixed Fock backend with density-matrix inputs, unitary evolution,
  vacuum/thermal attenuation, ideal photon counting and noisy homodyne conditioning.
- Finite-energy GKP comb resources, logical displacements, stabilizer diagnostics,
  modular shift decoding and finite-ancilla syndrome-correction patterns.
- Optional JAX execution with differentiable projected Fock evolution, vacuum loss,
  fixed measurement branches, likelihoods and observables. Reparameterization and
  score-function primitives support explicit estimator construction.
- Circuit, resource graph, measurement pattern, command and compilation drawings;
  concise object representations; documented public inputs, outputs and conventions.
- MkDocs Material website, source-derived API reference, 24 executable tutorials,
  ten reproducible projects, five executed notebooks and nine SVG assets.
- Contributor policies, issue/PR templates, citation metadata, documentation CI,
  Pages workflow and measured Codecov upload configuration.

## Scientific and presentation limits

The target gate set is universal in the continuous-variable sense, but the supplied
synthesis front end is **not an arbitrary-unitary compiler**. It accepts the documented
polynomial families through degree four. Quartic/Kerr lowering uses approximate
commutator/product formulas, has no certified global error bound and can produce very
large patterns. Product-formula error, finite-resource filtering and Fock truncation
must be studied independently.

Mixed evolution uses dense truncated density matrices. The memory guard bounds one
matrix, not peak workspace use. Thermal gain can lose probability beyond the cutoff.
Fock heterodyne/general-dyne detection remains unsupported. GKP resources have finite
peaks and numerical projection error; syndrome correction is infrastructure, not a
fault-tolerance threshold or logical-error-rate claim.

JAX requires double precision and supports fixed topology and explicit measurement
outcomes. It does not make the general stochastic simulator differentiable. Its
projected generators require cutoff convergence, and zero-probability branches have
undefined conditional gradients. Thermal/noisy measurement differentiation and
arbitrary Python callable expressions remain unsupported.

The documentation covers the public API and executable examples, but does not provide
a hardware export specification, certified synthesis-cost/error theory, a fault-tolerant
GKP architecture or exhaustive platform performance benchmarks. Research APIs remain
experimental; the feature matrix and numerical policy define the supported contracts.

Visualizations are static Matplotlib/SVG. Compilation correspondence uses actual
trace metadata and rejects stale traces; runtime callables are not JSON-serializable.
The combined figure limits patterns to 24 source gates and 150 nodes for readability.
Large layouts can overlap, and there is no interactive editor or hardware scheduler.

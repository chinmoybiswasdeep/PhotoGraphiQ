# v0.3 preimplementation audit

Baseline 0b07f43 on validation/v0.2-physics-hardening had eleven flat Markdown pages and four terse scripts. It lacked a site, generated API reference, notebooks, circuit drawing, trace provenance, coverage upload and community templates. Original rotation/squeeze labels were lost in symplectic matrices. The approved scope added documentation/visualization plus experimental mixed Fock, nonlinear synthesis, GKP and differentiation. Preserve historical validation evidence and distinguish local checks from remote CI.

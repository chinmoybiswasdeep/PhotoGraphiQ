# Adding a backend

Implement BaseBackend reset, prepare, entangle, displace, rotate, squeeze, beamsplitter, measure and get_state. Advertise only implemented capabilities and validate resources before allocation. Maintain labels through destructive measurements and requested output reordering. Use statistical covariance and hbar=2 interface units. Add independent analytical tests, native comparisons, unsupported-operation checks and memory guards. Mixed outputs do not imply mixed trajectory evolution.

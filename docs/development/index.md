# Contributing

Install `python -m pip install -e ".[dev,docs,autodiff]"`. Create a focused branch from the current development baseline. Keep physics changes separate from presentation changes. Before a PR, run tests, Ruff lint/format, mypy, strict documentation build and package build. Explain numerical conventions and any approximation in the PR. See the repository CONTRIBUTING.md for commands and review policy.

See [numerical policy](../validation/numerical-policy.md), [API](../api/index.md) and the [feature matrix](../validation/feature-matrix.md).

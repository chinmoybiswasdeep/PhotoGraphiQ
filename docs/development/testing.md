# Running tests

Run `python -m pytest` for the installed core test suite. Categories include tests/unit, tests/analytical, tests/protocols, tests/regression, tests/integration, tests/native (C++ engines), tests/cross_backend, tests/validation (independent references), tests/fock, tests/mixed_fock, tests/non_gaussian, tests/cutoff, tests/compilation, tests/gkp, tests/sampling, tests/flow, tests/calculus, tests/visualization, tests/gpu, tests/cudaq_adapter, tests/ml, tests/piquasso_reference, tests/graphix_reference and tests/autodiff. tests/autodiff needs JAX (`autodiff` extra); tests/piquasso_reference needs the `piquasso` extra (included in `dev`); tests/graphix_reference needs Graphix; GPU tests skip with a reason without CuPy or a device; the real-CUDA-Q test skips without `cudaq`. `python experiments/validate_release.py --output .validation` preserves gate logs. Add a regression for a demonstrated bug and keep independent numerical error budgets explicit.

See [numerical policy](../validation/numerical-policy.md), [API](../api/index.md) and the [feature matrix](../validation/feature-matrix.md).

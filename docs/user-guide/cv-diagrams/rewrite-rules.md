# Rewrite rules

Every rule is an object in `RULES` (a dict keyed by rule name). It has a `name`, an
`equivalence` class, an `assumptions` string, a `source` string, `find(diagram)` (a list of
matches) and `apply(diagram, match)`. The statements and proofs are in
[the theory note, §4](../../theory/CV_ZX_FOUNDATIONS.md).

## Equivalence classes

From strongest to weakest:

| Class | What is preserved | What may change |
|---|---|---|
| `exact-instrument` | The full conditional instrument. For every input, the joint law of the output Wigner variables and the records is unchanged. This preserves every record density, every conditional state and the averaged channel. | Global or outcome-dependent (branch) phases. These are invisible to density operators and are written to the trace when known. |
| `exact-channel` | The outcome-averaged channel (X, Y, d). Used only where the rewritten region has no records. | Nothing observable. |
| `logical` | The ideal (infinite-squeezing) map: the affine part (X, d) of the channel, at every finite squeezing. | The finite-squeezing noise Y and the set of records. **Never** treated as physical equality. |

## Rule table

| Rule (`RULES` key) | Class | Assumptions (from the code) | Proof source |
|---|---|---|---|

| `squeezing-fusion` | exact-instrument | Same-axis (q) squeezers on the same mode, wire-adjacent | S(r₁)S(r₂) = S(r₁ + r₂): one-parameter subgroup generated by qp + pq |
| `shear-fusion` | exact-instrument | Quadratic phases on the same mode, wire-adjacent | exp(i s₁q²/4) exp(i s₂q²/4) = exp(i(s₁ + s₂)q²/4): commuting functions of q |
| `displacement-fusion` | exact-instrument | Constant displacements on the same mode, wire-adjacent | Weyl relation D(b)D(a) = exp(i(a_q b_p − a_p b_q)/4) D(a + b), ħ = 2. The phase is recorded as `scalar`. |
| `identity-removal` | exact-instrument | Box at its identity parameter: angle 0 mod 2π (rotation, beam splitter), r = s = g = 0, zero displacement or feed-forward, identity `Symplectic`, η = 1 loss, `PhasePolynomial` of degree ≤ 0 (its c₀ is recorded as a global phase) | Each generator at its identity parameter is the identity |
| `commute` | exact-instrument | Adjacent boxes on disjoint bosonic wires, with no record dependency between them | Operations on disjoint tensor factors commute; classical dependencies are kept |
| `symplectic-fusion` | exact-instrument | Two Gaussian unitary boxes; the second is the next box on *all* modes of the first | (S₂, d₂)∘(S₁, d₁) = (S₂S₁, S₂d₁ + d₂). An unrecorded global phase comes from the displacement order. |

| `feedforward-merge` | exact-instrument | Two outcome-affine displacements on the same mode, wire-adjacent | Displacements compose up to a phase. With outcome-dependent gains the phase depends on the branch, which is invisible at the density level. |
| `cz-q-measurement-to-feedforward` | exact-instrument | `CZ(u, v, g)` followed on u (wire-adjacent) by an **ideal** homodyne of q_u (θ = 0 or π); any state of u and v | CZ = exp(i g q_u q_v/2) commutes with q_u, and ⟨m\|_u CZ = exp(i g m q_v/2) ⟨m\|_u. | `phase-polynomial-fusion` | exact-instrument | Two exp(i f(q)) gates on the same mode, wire-adjacent; f, g real polynomials; exact on the Schwartz space | Nagayoshi et al., PRR 7, 033141 (2025), q-spider fusion Eq. (70), 1 → 1 case: exp(i f(q)) exp(i g(q)) = exp(i (f + g)(q)) |
| `displacement-through-phase-polynomial` | exact-instrument | `Displacement(dq=a, dp=0)` followed (wire-adjacent) by exp(i f(q)) | X(a)† f(q) X(a) = f(q + a), so exp(i f(q)) X(a) = X(a) exp(i f(q + a)). Nagayoshi et al., displacement rule Eq. (79), 1 → 1 case. The phase is moved before the displacement with shifted coefficients. |
| `teleport-chain-resynthesis` | **logical** | A maximal chain of standard corrected teleportation steps on one logical wire, with equal resource squeezing, whose records are read only by their own corrections | The exact wire channel S = T(k_L)⋯T(k₁) of the chain (`gaussian.wire_channel`), and a verified exact re-decomposition of S into the fewest steps found (0–3 special forms are tried, then the compiler's decomposition) |

"Wire-adjacent" means that no box between the two matched boxes touches the matched wires.
Boxes on other wires may sit in between. Moving past them is the `commute` rule.

The rules are grouped in `rules.GAUSSIAN_RULES` (the first eleven rows, `commute` included),
`rules.NON_GAUSSIAN_RULES` (the two phase-polynomial rules) and `rules.MBQC_LOGICAL_RULES`
(teleport-chain resynthesis).

## Applying a rule

```python
from photographiq.calculus.cv_diagrams import CVDiagram, Rotation, Squeezer, apply_rewrite

d = CVDiagram((0, 1), (Rotation(0, 0.2), Squeezer(1, 0.1), Rotation(0, 0.3)), (0, 1))
out = apply_rewrite(d, "rotation-fusion")          # first match; or pass match=...
print(len(d.boxes), len(out.boxes), out.trace[-1].rule, out.trace[-1].equivalence)
# 3 2 rotation-fusion exact-instrument
```

`apply_rewrite(diagram, rule, match=None)` accepts a rule name or a `Rule` object. It raises
`ValueError` if the rule does not match, or if `match` is not one of `rule.find(diagram)`.

**Rewrites never mutate.** They return a new `CVDiagram` with one more `RewriteStep` in
`trace`. A `RewriteStep` has the fields `rule`, `affected` (box indices), `before` and
`after` (box dictionaries), `equivalence`, `assumptions`, `source`, `scalar` (a recorded phase,
or `None`) and `extra` (for example `steps_before` and `steps_after` for resynthesis).
`trace_json(diagram, **extra)` serialises the whole trace.

## Teleportation steps

`teleport_steps(d)` lists the standard corrected wire steps that `compile_circuit` produces:
`Prepare.squeezed(b, r)`, `CZ(a, b, 1)`, an ideal `Homodyne(a, θ, key)` with sin θ ≠ 0, and
`Feedforward(b, {key: (−1/sin θ, 0)})`, all wire-adjacent. Each entry gives the input and
output wires, the shear k = cot θ, the squeezing r, the box indices and the record key. The
resynthesis rule works on maximal chains of these steps.

## What is not a rule

No other rewrite is implemented. In particular there are no multi-leg spiders, Fourier boxes,
bialgebra, copy or antipode rules, no rules that change heralding probabilities, and no GKP
logical rewrites. See [Limitations](limitations.md).
